## What This Is

This is a guided spiritual journey built for Claude. It walks people through a structured, 5-phase inner journey — from slowing down and reconnecting with stillness, to releasing limiting beliefs and forgiveness, aligning purpose and business with spirit, shifting into abundance, and building a spiritual practice that actually lasts.

By the end, Claude delivers the **Soul Alignment Package** — 5 personalized pieces built from everything the person shared throughout the journey.

**This is not a religious program.** It is not affiliated with any faith, denomination, or spiritual tradition. It meets you wherever you already are.

---

## The 5 Phases

| Phase | Focus |
|-------|-------|
| Phase 1: The Inward Turn | Stillness + Listening Within |
| Phase 2: The Release | Limiting Beliefs + Forgiveness |
| Phase 3: The Alignment | Higher Purpose + Business-Spirit Connection |
| Phase 4: The Expansion | Abundance + Vision |
| Phase 5: The Integration | Gratitude + Sustaining the Path |

---

## What They Walk Away With — The Soul Alignment Package

1. **The Soul Mirror** — the deeper longing beneath everything they shared, reflected back in their own words
2. **The Growth Map** — the specific moments of breakthrough across the journey, named and honored
3. **The Guarded Places** — where they're still holding back, offered as an invitation, not a callout
4. **The Personalized Spiritual Practice** — a sustainable daily practice built around their real life, not a generic suggestion
5. **One Spiritual Truth** — a single truth or question, specific to their story, to carry with them

## Install This Skill

**Option 1 — Download and install:**
1. Download `powerhouse-spiritual-coach.plugin` from this repo
2. Run:
```bash
claude plugin install /path/to/powerhouse-spiritual-coach.plugin
```

Once installed, just start a conversation. Say anything — "I need spiritual guidance," "I'm ready for my spiritual journey" — and it begins.
